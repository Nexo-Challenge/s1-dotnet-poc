# Requisitos — Sprint 1

Disciplina: Advanced Business Development with .NET.

Fonte: `2TDS Agosto - Marinha 2026 - 1º Semestre V2.pdf`, seção Advanced Business Development with .NET 1/3–3/3.

Todos os itens estão pendentes. Este checklist não substitui orientações atualizadas do professor/portal.

- [ ] Aplicação console .NET com pelo menos uma entidade coerente com a solução.
- [ ] Validar atributos e implementar pelo menos uma regra de negócio.
- [ ] Tratar erros com try/catch sem encerrar indevidamente a aplicação.
- [ ] Cadastrar, listar todos os registros e buscar por um critério.
- [ ] Persistir entre execuções: JSON OU Entity Framework Core + Oracle; ambas as opções têm a mesma pontuação.
- [ ] Funcionalidade diferente ou complementar à API Java; não duplicar a entrega Java.
- [ ] Repositório público, .gitignore e commits reais de todos os integrantes.
- [ ] README com grupo, nomes/RMs, solução, escopo, arquitetura, execução e parágrafo explicando como o .NET se aplica à solução.
